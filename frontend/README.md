# Traof Certificate Management System - Frontend

## Setup
1. Clone the repository.
2. Run `npm install` in the `frontend` directory.
3. Create a `.env` if you need to override the API URL:
   ```env
   VITE_API_URL=http://localhost:5000/api
   ```
4. Run the development server:
   ```bash
   npm run dev
   ```

## Features
- Premium RTL (Arabic) Dashboard.
- Department and Program Management.
- Participant directory with Excel Bulk Import.
- Certificate Generation and Verification via QR Code.
